Expert Sleepers ES-9 User Manual (Firmware v1.3)1. Overview & Technical SpecsThe Expert Sleepers ES-9 is a DC-coupled USB audio interface in Eurorack format, offering 14 inputs and 12 outputs alongside integrated DSP mixing, routing, and expansion headers. Configuration Tool & DSP ArchitectureConfigured via the Expert Sleepers Config Tool (standalone app or Web MIDI in Chrome).Processing BlocksThe ES-9 internal routing consists of three primary processing blocks linked by 16 internal mono summing busses:USB Audio: 16 inputs / 16 outputs to/from DAW.Mixer 1: $8 \times 8$ crosspoint mixer.Block 3 (Selectable): S/PDIF Digital Processor OR Mixer 2 ($8 \times 8$ crosspoint mixer).Signal Source OptionsInputs and outputs of all blocks can select from:Hardware Inputs 1–14Internal Busses 1–16USB Outputs 1–16 (from DAW)Mixer 1 Outputs 1–8S/PDIF Processor Outputs 1–25. Mixer Controls & FilteringInput EQEach mixer input features up to 4 bands of parametric DSP EQ:Filter Types: Low Pass ($1^\text{st}$ & $2^\text{nd}$ order), High Pass ($1^\text{st}$ & $2^\text{nd}$ order), Low Shelf, High Shelf, Peak, Phase Invert.Parameters: Frequency, Q (bandwidth), Gain.DC Blocking & OffsetsInput DC Blocking: Switchable in pairs (1/2, 3/4, 5/6, 6/7, 9/10, 11/12, 13/14). Must be disabled for CV signals; recommended ON for audio to maximize dynamic range.Output DC Offsets: Applied per 3.5mm output via hardware mixer calibration.MIDI CC Control MapMixers can be controlled via fixed MIDI CCs when enabled in settings:Faders start at CC 0 (Mix 1, Input 1) and increment by channel, then by mix (e.g., Mix 1 Input 8 = CC 7; Mix 2 Input 1 = CC 8; Mix 8 Input 8 = CC 63).For linked stereo pairs, the lowest-numbered CC is used for level, and the right channel's CC is repurposed for Pan.6. Firmware Update ProcedureFirmware is updated over USB using the ExpertSleepersDFU utility:Download and extract the target firmware .dfu file from Expert Sleepers.(Windows only) Uninstall the custom Expert Sleepers audio driver before updating.Run ExpertSleepersDFU and select the .dfu file.Verify the tool reports "Expert Sleepers Ltd: ES-9" in Runtime Mode.Click REBOOT DEVICE to put the module into DFU bootloader mode.Click UPDATE DEVICE to flash the firmware. The ES-9 reboots back into Runtime Mode automatically upon completion.
